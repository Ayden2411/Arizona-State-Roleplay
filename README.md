# Arizona-State-Roleplay
What the bot does is Session Announcements
Starts SSU, LOW, FULL, and SSD sessions using buttons and sends an embed message.

Button Based Controls
Uses buttons instead of typing commands to start sessions.

Role Permissions
Only people with a set role can start sessions.

Channel Restrictions
Commands can only be used in specific channels you choose.

Custom Session Messages
Lets you set the message text, image, and ping (@role).

SSU Vote System
Players can vote for an SSU using a button. Once enough votes are reached, staff and the command runner get notified.

Database Saving
All settings are saved in a database and stay after restarts.


You set it up by running ./setup and then to see the session buttons do ./sessionpanel

And then ./ssuvote to send a vote.
